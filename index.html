👤 Gestão de clientes
/gerar [qtd]
Gera tokens. Ex: /gerar 3
/clientes
Lista todos os clientes com status e validade.
/renovar CHAT_ID
Renova acesso por mais 30 dias.
/revogar CHAT_ID
Revoga acesso imediatamente.
/stats
Resumo geral: ativos, expirados, tokens, receita.
⚙️ Configurar cliente
/config CHAT_ID modo completo|simples
Completo: botões assistir + site/app. Simples: só assistir.
/config CHAT_ID site URL
Define site personalizado do cliente.
/config CHAT_ID site remover
Volta ao site padrão.
